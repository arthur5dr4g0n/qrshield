Politique de confidentialité — QRShield

Dernière mise à jour : 10 juin 2026

QRShield est une application web (PWA) qui analyse les QR codes avant de les ouvrir. Cette page explique quelles données sont utilisées et comment.

1. Caméra

L'application utilise votre caméra uniquement pour lire les QR codes. Les images ne quittent jamais votre appareil. Aucune photo n'est enregistrée ni envoyée à un serveur.

2. URLs analysées

Quand un QR code est scanné, l'URL qu'il contient peut être envoyée à des services tiers pour vérification :

  • VirusTotal (virustotal.com) — pour vérifier si l'URL est connue comme malveillante. Soumission soumise à la politique de confidentialité de VirusTotal.
  • urlscan.io (urlscan.io) — analyse complémentaire. Les URLs soumises peuvent être visibles publiquement sur leur site. Ne scannez pas de QR codes contenant des liens privés ou des tokens.

Ces envois ne se font que si vous avez configuré vos clés API dans les paramètres de l'application.

3. Clés API

Vos clés API VirusTotal et urlscan.io sont stockées uniquement sur votre appareil (localStorage). Elles ne sont jamais transmises à nos serveurs.

4. Proxy CORS

Un proxy intermédiaire (Cloudflare Worker) est utilisé pour relayer les appels vers VirusTotal, car ce service ne supporte pas les appels directs depuis un navigateur. Ce proxy ne stocke aucune donnée et ne conserve aucun journal des URLs analysées.

5. Données collectées

Aucune donnée personnelle n'est collectée. L'application ne crée pas de compte utilisateur, ne suit pas votre activité et n'utilise pas de cookies de traçage.
